# La Mediterránea Store — V1 scope

## Current objective
Rebuild the existing static merchandising page as a clean, responsive storefront without turning a limited-budget project into a custom commerce platform.

## This checkpoint includes
- Next.js + TypeScript foundation.
- Current public catalog and current web prices.
- Real product imagery migrated from the existing page.
- Category filtering.
- Color and size selection where the current catalog defines those variants.
- Functional client-side cart with quantity controls and persistence in the browser.
- Responsive desktop/mobile UI.
- Basic accessibility and reduced-motion handling.
- Metadata and clean project structure.
- CI verification for catalog integrity, TypeScript and production build.

## Explicitly deferred
- Supabase / database / admin panel.
- Mercado Pago / checkout / payment confirmation.
- WhatsApp ordering or contact flow.
- Stock persistence.
- Customer accounts.
- Coupons, CRM, invoicing and logistics integrations.
- Production deployment.

## Current Definition of Done
A customer can browse the full current catalog, choose available color/size variants, add items to a persistent cart and adjust quantities on desktop or mobile. The project builds cleanly in CI and is ready for the next integration stage without rewriting the storefront.
